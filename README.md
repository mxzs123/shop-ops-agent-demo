# shop-ops-agent-demo

小さなお店の商品管理を、自然言語で任せられる運営エージェントのデモです。
「胃腸薬を検索して」「この商品の価格を 980 円にして」と頼むと、エージェントが商品マスタを検索し、
**変更のプレビューを見せ、人が確認してから**実行します。

モデルは Claude（Vercel AI SDK + `@ai-sdk/anthropic`）、開発は Claude Code で行いました。

> **このリポジトリについて**
> 実際に業務で運用しているエージェントをもとに、公開用に切り出したデモ版です。
> 収録している商品・メーカー・画像はすべて架空のもので、実在の企業や店舗のデータは含まれていません。
> 既定では `fixtures/` の架空カタログだけで動き、Claude API 以外の外部システムには接続しません。

## 何ができるか

- **検索**：名前・状態・カテゴリなどで商品を探し、結果をカードで表示
- **編集・登録・削除**：1 件でも数百件でも、同じ流れで処理
- **範囲指定の一括編集**：「販売中の商品すべて」のような条件で対象を固定してから変更
- **画像つきの指示**：商品画像をアップロードして表紙や画像一覧を差し替え

## 安全設計

AI に書き込みを任せるうえで、次の仕組みを入れています。

| 仕組み | 内容 |
| --- | --- |
| 計画と実行の分離 | 書き込みは必ず 2 段階。`plan` 系ツールはプレビューを作るだけでデータを変更しない |
| モデルは変更内容を直接渡せない | 実行ツール `goods_execute` が受け取るのは `previewId` だけ。変更内容はサーバー側に凍結されたものを使う |
| 人の明示的な確認 | 最新のユーザー発言に確認の意思があるかをサーバー側でも検証（`src/confirmation.ts`、日本語・中国語・英語に対応）。「ちょっと待って」などが混ざれば未確認として扱う |
| 古いプレビューの拒否 | プレビュー作成後に元データが変わっていたら実行を拒否 |
| 書き込みスイッチ | 実環境への書き込みは `ADMIN_AGENT_ALLOW_WRITES=true` を明示しない限り禁止 |
| 監査ログ | 実行内容を JSONL で記録（`src/audit-log.ts`） |
| 部分失敗の扱い | 一括実行は成功・スキップ・失敗の件数を返し、失敗分だけ再実行できる |

処理の流れ：

```
検索 → 編集可能な現在値を取得 → プレビュー作成（書き込みなし）
     → 人が確認 → 実行 → 監査ログ
```

## 動かし方

Node.js 22 と pnpm 9 で動作を確認しています。

```bash
pnpm install
cp .env.example .env   # ANTHROPIC_API_KEY を設定（画面の「設定」からでも入力可）
pnpm dev
```

<http://127.0.0.1:18083> を開きます。

fixture モードでの実行は、起動中のプロセスのメモリ上だけを書き換えます。
再起動すると `fixtures/goods.example.json` の状態に戻ります。

### 検証

```bash
pnpm typecheck
pnpm test    # fixture でツール一式を端から端まで実行（API キー不要）
pnpm build
```

## 構成

| パス | 役割 |
| --- | --- |
| `app/api/chat/route.ts` | AI SDK によるオーケストレーション、システムプロンプト、ツール定義 |
| `app/api/tools/[tool]/route.ts` | ツールを直接呼ぶエンドポイント |
| `src/goods-tools.ts` | 検索・プレビュー・実行の業務ロジック |
| `src/goods-tool-runner.ts` | 監査ログつきのプレビュー実行 |
| `src/bulk-preview-store.ts` | プレビューをサーバー側で凍結して保持 |
| `src/confirmation.ts` | サーバー側の確認ゲート |
| `src/message-context.ts` | モデルに送る履歴の圧縮 |
| `src/model-provider.ts` | Claude の設定（既定 `claude-opus-5-5`、`ANTHROPIC_MODEL` で変更可） |
| `src/fixture-admin-client.ts` | 架空カタログ用のバックエンド |
| `src/admin-client.ts` | 実際の管理バックエンドに接続する場合のトランスポート |
| `components/tool-cards/` | 検索結果・プレビュー・実行結果のカード |
| `fixtures/goods.example.json` | 架空の商品 100 件 |

## クレジット
